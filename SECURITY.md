# Security policy

Report vulnerabilities in this scanner by opening a private GitHub security advisory on [K-Almahamid/security-scan](https://github.com/K-Almahamid/security-scan) or by contacting the repository owner. Do not file a public issue that includes a working exploit against a third-party repository.

This project scans repositories you point it at. It does not authorize scanning systems you do not own or operate. Do not send secrets, live credentials, or raw customer data in a report.

A scan report is not proof that a repository is free of vulnerabilities. Failed and skipped tools are not passing checks. The operational trust boundaries are described in [docs/security-model.md](docs/security-model.md).
